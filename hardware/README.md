# Grey alien head (v1 print)

Designed in SolidCraft. Working copies also live on Brad's laptop:
`C:\Users\knigh\OneDrive\Well Files\Bravo Kilo\Solidcraft\`

| File | Print notes |
|---|---|
| `grey_alien_display.sc` / `.step` | SolidCraft design / STEP for other CAD tools |
| `alien_front_shell.stl` | 171 x 177 mm (fits the A1 Mini). Print face-down as exported |
| `alien_back_lid.stl` | Flip so the flat back is on the bed. Has the stand socket and USB-C opening |
| `alien_lens.stl` | 131.6 x 32.6 x 2 mm. Dark translucent filament, or a template for smoked acrylic |
| `alien_stand.stl` | Base-down, 4 walls. Its tongue slides up into the lid socket |

Assembly: lens into the window, board on the lens (header through either side notch),
ESP32 on end in the slot by the left screw post, USB-C side facing up toward the top of the head.
Lid held by 4 M3 pan-head screws.
